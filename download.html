How to install on Android

  1. When the download finishes, tap the notification or open Downloads and tap IlmCoreAI.apk.
  2. If Android asks, tap Settings and allow your browser to install unknown apps, then go back.
  3. Tap Install. If Play Protect shows a warning, tap More details → Install anyway. The app isn't from the Play Store.
  4. Open IlmCore AI and sign in or create a free account.

How to install on Windows

  1. When the download finishes, open your Downloads folder and double-click Ilmcore.exe.
  2. If Windows shows Windows protected your PC, click More info → Run anyway. The app isn't from the Microsoft Store.
  3. Follow the installer, then open IlmCore AI from the Start menu and sign in or create a free account.

Prefer no download? Open IlmCore AI in Edge or Chrome and click the Install icon in the address bar.
