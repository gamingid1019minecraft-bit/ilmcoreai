Free IlmCore AI API

Use IlmCore AI anywhere — your own app, a Discord bot, a website, or a Roblox game. One endpoint, plain JSON.

Base URL: https://ilmcoreback.vercel.app

1. Get your API key

Create a free account, log in to get a session token, then create a key. The key is shown once, so copy it and keep it secret. Never put it in client-side code.

Log in
curl -X POST https://ilmcoreback.vercel.app/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"YOUR_PASSWORD"}'
# returns {"token":"SESSION_TOKEN", ...}
Create a key
curl -X POST https://ilmcoreback.vercel.app/v1/keys \
  -H "Authorization: Bearer SESSION_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"my-app"}'
# returns {"api_key":"ilm_...", ...}

Manage your keys: GET /v1/keys lists them (previews only) and DELETE /v1/keys/KEY_ID revokes one. Use the same Authorization: Bearer SESSION_TOKEN header as when you created it.

2. Send a message

POST https://ilmcoreback.vercel.app/v1/chat with your key in the Authorization: Bearer ilm_... header (or X-API-Key). The reply comes back as JSON: {"reply": "...", "session_id": "..."}. Send the session_id back next time to keep the conversation going. Leave out max_chars for long answers, and set format to markdown to keep code blocks when you ask for code.

curl
curl -X POST https://ilmcoreback.vercel.app/v1/chat \
  -H "Authorization: Bearer ilm_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message":"Tell me a joke","max_chars":200}'
Python
import requests

r = requests.post(
    "https://ilmcoreback.vercel.app/v1/chat",
    headers={"Authorization": "Bearer ilm_YOUR_KEY"},
    json={"message": "Hello!"},
)
print(r.json()["reply"])
JavaScript
const r = await fetch("https://ilmcoreback.vercel.app/v1/chat", {
  method: "POST",
  headers: {
    "Authorization": "Bearer ilm_YOUR_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ message: "Hello!" }),
});
console.log((await r.json()).reply);
Roblox (Luau, server script)
local HttpService = game:GetService("HttpService")

local res = HttpService:RequestAsync({
  Url = "https://ilmcoreback.vercel.app/v1/chat",
  Method = "POST",
  Headers = {
    ["Content-Type"] = "application/json",
    ["X-API-Key"] = HttpService:GetSecret("IlmCoreKey"),
  },
  Body = HttpService:JSONEncode({ message = "Hello!", max_chars = 200 }),
})
print(HttpService:JSONDecode(res.Body).reply)

Roblox tip: turn on Allow HTTP Requests in your game's Security settings, store the key as a Secret, and only call the API from a server Script.

Request fields

FieldTypeWhat it does
messagestringRequired. What you want to say. Up to 2000 characters.
session_idstringPass the id from the last reply to keep the conversation context.
personastringExtra instructions, like "You are a pirate shopkeeper in my game."
max_charsnumberHard limit on reply length. Handy for game chat bubbles. Leave it out for long replies like full code files.
formatstringplain (default, no markdown) or markdown.
fastbooleanOn by default. Uses the fastest models for quick replies.

Errors and limits

StatusMeaning
400Missing or invalid message.
401Missing, invalid or revoked API key.
404session_id not found for this key's owner.
413Message too long (over 2000 characters).
429Rate limit hit: 20 requests per minute and 500 per day per key by default. Check the Retry-After header and try again later.
503All AI providers are busy. Retry shortly.

The API is text chat only (no file or image uploads).

Frequently asked questions

Everything you might want to know before signing up.

Is IlmCore AI really free?

Yes. There is no paid tier and no credit card required. All features — chat, image generation, voice, file upload — are available the moment you sign up.

What makes IlmCore different from other AI chatbots?

Three things: (1) it does many things at once — chat, images, voice, files, web search — in one place; (2) it's free without asterisks; (3) it uses multiple AI providers behind the scenes so it stays up when others go down.

Can IlmCore AI read my files?

Yes. Upload a PDF, DOCX, image, or an entire folder of code and ask questions about it. IlmCore extracts the text and reasoning from what you upload.

Can IlmCore AI write long code?

Yes. Ask for a full script, app or project and it writes the long code in a single reply, in syntax-highlighted code blocks. You can also ask for downloadable files.

Does it work on my phone?

Yes — IlmCore AI runs entirely in your browser. It supports voice input (speak to it) and voice output (it reads replies to you) on both Android and iOS.

How do I switch to my own AI backend?

Open Settings → scroll to Advanced — custom backend → enter any OpenAI-compatible URL that serves /health, /auth/*, /sessions, and /chat → click Test then Save. The app reloads and points at your backend.

Does IlmCore AI have an API?

Yes, and it's free. Log in, create an API key with POST /v1/keys, then send messages to POST /v1/chat. See the API section for copy-paste examples in curl, Python, JavaScript and Roblox Luau.
